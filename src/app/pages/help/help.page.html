Manual de Usuario y Ayuda
Guía de Uso del Sistema de Gestión

Bienvenido al manual interactivo integrado de la plataforma. A continuación se detallan las funcionalidades principales implementadas según las especificaciones técnicas del proyecto.

1. Roles de Usuario y Control de Acceso (RBAC)

El sistema soporta dos perfiles con permisos diferenciados mediante Guards:

  • Administrador: Acceso completo al Cuadro de Mando, catálogo de registros, creación y borrado de elementos.
  • Usuario Estándar: Acceso al catálogo de registros para consulta y alta; rutas administrativas protegidas.
 2. Formularios y Validaciones Asíncronas

Tanto en el Registro de Usuario como en el Alta de Registros, los formularios incorporan validaciones reactivas con comprobación asíncrona contra el backend simulado:

  • Verificación en tiempo real de correos electrónicos no duplicados.
  • Verificación de códigos únicos de producto (formato y disponibilidad).
  • Retroalimentación visual accesible (estados PENDING, valid e invalid).
 3. Componentes Visuales Reutilizables
  • StatCardComponent: Widget modular para la visualización de métricas y tendencias (KPIs).
  • DataTableComponent: Tabla agnóstica con barra de búsqueda instantánea, selector de categorías, paginación y eventos hacia el contenedor padre.
 4. Exportación de Informes

Desde la barra superior o desde el panel de control puede descargar en un clic el inventario completo en formato CSV normalizado con codificación UTF-8 BOM, compatible con Microsoft Excel y hojas de cálculo.
