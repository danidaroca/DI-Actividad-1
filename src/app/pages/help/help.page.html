Manual de Usuario y Ayuda
Guía de Uso del Sistema de Gestión

Bienvenido al manual interactivo integrado de la plataforma. A continuación se detallan las funcionalidades principales implementadas según las especificaciones técnicas del proyecto.

1. Roles de Usuario y Control de Acceso (RBAC)

El sistema soporta dos perfiles con permisos diferenciados mediante Guards:

  • Administrador: Acceso completo al Cuadro de Mando, analítica de gráficos Chart.js, catálogo de registros, creación y borrado de elementos.
  • Usuario Estándar: Acceso al catálogo de registros para consulta, alta y exportación; ruta de Cuadro de Mando protegida.
 2. Formularios y Validaciones Asíncronas

Tanto en el Registro de Usuario como en el Alta de Registros, los formularios incorporan validaciones reactivas con comprobación asíncrona contra el backend simulado:

  • Verificación en tiempo real de correos electrónicos no duplicados.
  • Verificación de códigos únicos de producto (formato regex y disponibilidad).
  • Retroalimentación visual accesible (estados PENDING con spinner, válido con check verde y alertas).
 3. Componentes Visuales Reutilizables
  • StatCardComponent: Widget modular para la visualización de métricas y tendencias (KPIs) con temas cromáticos configurables.
  • DataTableComponent: Tabla agnóstica con barra de búsqueda instantánea, selector dinámico de categorías, paginación y eventos hacia el contenedor padre.
 4. Cuadro de Mando Ejecutivo y Analítica con Chart.js

El panel de control integra gráficos interactivos mediante Chart.js para el rol Administrador:

  • Gráfico de Barras: Representa la distribución de inventario por categoría (permite conmutar en tiempo real entre unidades físicas y valoración monetaria en euros).
  • Gráfico Doughnut: Refleja la cuota porcentual de valor económico de cada familia de artículos.
  • Orquestación Concurrente: Carga sincronizada mediante forkJoin de métricas, registros y flujo en tiempo real NoSQL.
 5. Exportación de Informes (PDF y CSV)

El sistema permite la extracción tabulada de la información en formatos estándar para auditorías:

  • Informe PDF Oficial: Generado con jsPDF y jspdf-autotable, formateado en orientación horizontal con membrete corporativo, tarjetas resumen de KPIs, colores de estado y paginación.
  • Informe CSV Delimitado: Exportación rápida compatible con Microsoft Excel y LibreOffice Calc (codificación UTF-8 con marca BOM).
 6. Documentación Técnica Automatizada (Compodoc)

El proyecto cuenta con documentación estandarizada generada por Compodoc. Ejecuta en terminal: 

npm run compodoc:build
npm run compodoc:serve

Para explorar en el navegador el árbol de componentes, rutas, servicios y cobertura del código.
